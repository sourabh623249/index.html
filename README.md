# Modern Todo App

A beautiful, feature-rich todo application built with vanilla HTML, CSS, and JavaScript. Stay organized and boost your productivity with an intuitive interface and powerful features.

## Features

### ✨ Core Functionality
- **Add Tasks**: Create new tasks with titles, descriptions, and priority levels
- **Mark Complete**: Check off completed tasks with visual feedback
- **Edit Tasks**: Modify task titles inline with a simple prompt
- **Delete Tasks**: Remove tasks you no longer need
- **Drag & Drop**: Reorder tasks by dragging them to new positions

### 🎨 Beautiful Design
- **Modern UI**: Clean, minimalist design with smooth animations
- **Dark/Light Theme**: Toggle between themes with a single click
- **Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Priority Badges**: Visual indicators for high, medium, and low priority tasks
- **Gradient Branding**: Beautiful gradient text and hover effects

### 🔍 Advanced Features
- **Search**: Find tasks quickly with real-time search functionality
- **Filtering**: View tasks by status (all, pending, completed) or priority level
- **Statistics**: Track your progress with completion rates and task counts
- **Local Storage**: Your tasks are automatically saved and persist between sessions
- **Keyboard Shortcuts**: Press Enter in the title field to quickly add tasks

### 📊 Task Management
- **Priority Levels**: Organize tasks with High, Medium, and Low priority
- **Descriptions**: Add detailed descriptions to provide context
- **Creation Dates**: See when each task was created
- **Visual States**: Completed tasks are visually distinct with strikethrough text

## Usage

1. **Adding Tasks**: Enter a task title and optionally add a description and set priority
2. **Completing Tasks**: Click the checkbox next to any task to mark it complete
3. **Searching**: Use the search bar to find specific tasks
4. **Filtering**: Click filter buttons to view tasks by status or priority
5. **Reordering**: Drag and drop tasks to reorganize them
6. **Theme Toggle**: Click the theme button (🌙/☀️) in the top-right corner

## Technical Details

- **Pure Vanilla JavaScript**: No frameworks or dependencies required
- **CSS Custom Properties**: Modern CSS with theme variables for easy customization
- **Local Storage API**: Persistent data storage in the browser
- **ES6+ Features**: Modern JavaScript with classes and arrow functions
- **Responsive Design**: Mobile-first approach with CSS Grid and Flexbox

## Browser Support

Works in all modern browsers that support:
- CSS Custom Properties (CSS Variables)
- Local Storage API
- ES6 Classes
- Drag and Drop API

## Getting Started

Simply open `index.html` in your web browser - no installation or setup required!
